# High Level Design (HLD)

## System Overview

The AI Project Manager is a full-stack web application for managing projects and tasks with AI-powered assistance.

## Architecture

User
↓
React Frontend
↓
Node.js + Express Backend
↓
MongoDB Database

The backend will also connect with an AI API to provide intelligent task suggestions.

## Main Modules

- Frontend
- Backend API
- Database
- AI Integration

## Backend Flow

Client
↓
Routes
↓
Controllers
↓
Models
↓
MongoDB

## Future Features

- Task management
- User authentication
- AI task suggestions
- Priority recommendations
- Project progress tracking
