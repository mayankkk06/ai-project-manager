# Product Requirements Document (PRD)

## Project Name
AI Project Manager

## Problem Statement
Managing projects and tasks manually can be difficult. Users may struggle to organize tasks, set priorities, and track project progress.

## Solution
AI Project Manager is a web application that helps users create and manage projects and tasks. AI features will help users organize tasks and provide useful suggestions.

## Target Users
- Students
- Developers
- Teams
- Project managers

## Core Features
- Create projects
- View projects
- Update projects
- Delete projects
- Manage tasks
- Track project status
- AI-powered task suggestions

## Technology Stack
- Frontend: React
- Backend: Node.js and Express.js
- Database: MongoDB
- AI Integration: AI API

## Success Criteria
Users should be able to manage projects easily and receive AI-based assistance for organizing their work.
